# spyre-dashboard Helm Chart

Developed by Anubhav Jana (Anubhav.Jana92@ibm.com, IBM Research, India)

Deploys the Spyre Model Coverage Dashboard on OpenShift.

## Prerequisites

- OpenShift cluster with the `route.openshift.io` API
- SSH key Secret created in the target namespace (see below)

## Install

```bash

`oc login` and then `oc project spyre-cdev`

# 1. Create the SSH key secret in your target namespace
oc create secret generic spyre-dashboard-ssh-key \
  --from-file=id_rsa=$HOME/.ssh/id_ed25519

# 2. Install the chart — namespace comes from -n flag
helm install spyre-dashboard ./helm-charts

# 3. Check the public URL
oc get route spyre-dashboard
```

## Upgrade (after pushing new commits to the branch)

```bash
oc delete pod spyre-dashboard
helm upgrade spyre-dashboard ./helm-charts
```

## Uninstall

```bash
helm uninstall spyre-dashboard
oc delete secret spyre-dashboard-ssh-key
```

## Key values

| Key | Default | Description |
|---|---|---|
| `git.repo` | `git@github.com:anubhavjana/torch-spyre-anu-forked.git` | Repo to clone |
| `git.branch` | `torch_spyre_dashboard` | Branch to clone (will be `main` once published) |
| `git.dashboardPath` | `tests/dashboard` | Path to dashboard.html inside repo |
| `ssh.secretName` | `spyre-dashboard-ssh-key` | Secret containing the SSH private key |
| `route.enabled` | `true` | Create an OpenShift Route |
| `route.host` | `""` | Custom hostname auto-generated by OpenShift |
| `security.runAsUser` | `1000` | UID for all containers |
